# 새솔 성장기록

Google Sheets를 브라우저에서 읽어 보여주는 정적 웹 프로그램입니다.
GitHub Pages에서 `main` 브랜치의 `/ (root)`를 게시 대상으로 설정합니다.

## 데이터 흐름

- GitHub에는 프로그램 코드만 저장합니다. 초기 환자 목록은 비어 있습니다.
- 접속한 브라우저가 연결된 Google Sheets의 XLSX 내보내기를 직접 요청합니다.
- GitHub Actions나 서버가 진료기록을 내려받거나 저장하지 않습니다.
- 기본 10초마다 확인하며 탭이 숨겨지면 확인을 쉬고 돌아올 때 재확인합니다.
- 자료 입력·수정은 원본 Google Sheets에서 합니다.
- 환자 순서와 화면 설정은 각 브라우저에 따로 저장됩니다.
- 인터넷 오류일 때 마지막으로 읽은 자료를 현재 화면에서 유지하고 재시도합니다.

## 접근 범위

이 구성은 로그인 없이 읽을 수 있는 Google Sheets가 필요합니다.
프로그램 주소를 아는 사람은 연결된 전체 환자 자료를 열람할 수 있습니다.
소스에는 시트 연결 식별자가 포함되어 있으며 로그인·권한 제한 기능은 없습니다.
GitHub에 진료 데이터 파일, JSON 백업, 기존 환자 자료가 내장된 HTML, Excel 파일을 올리지 마세요.
이 코드는 의료정보의 비공개 저장·권한 관리 시스템을 제공하지 않습니다.

## 실행 조건

최신 Chrome 또는 Edge 등 XLSX 압축 해제를 지원하는 브라우저와 인터넷 연결이 필요합니다.
공유 주소는 GitHub Pages 설정 화면에서 확인하세요. 저장소·계정·서비스 정책에 따라 유지됩니다.
로컬에서 HTML을 직접 여는 경우 브라우저 정책에 따라 Google 연결이 제한될 수 있습니다.
